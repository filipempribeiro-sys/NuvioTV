# MEDIA•HUB profiles

Profiles are optional account-scoped viewing contexts. The TV may proceed directly to Home when an account has one profile and no explicit profile-selection preference.

Each profile has a stable id, display name and optional avatar. Watch progress/favourites may become profile-scoped when the backend schema evolves; account-wide settings such as registered devices remain account-scoped.

Profile selection is remote-first, fast and visually consistent with MEDIA•HUB cards/focus. A cloud/profile failure must not trap the user before Home when local media functionality remains available.
