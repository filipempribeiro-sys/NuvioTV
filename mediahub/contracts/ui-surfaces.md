# MEDIA•HUB UI surfaces

## Splash
Dark MEDIA•HUB surface, official mark/wordmark, no Nuvio fallback branding. Fast transition; no artificial delay.

## Onboarding / account
Explains MEDIA•HUB once, then offers device pairing. QR state is explicit: preparing, ready, waiting, approved, expired, network error. Never show an indefinitely spinning QR when discovery/backend is unavailable.

## Home
Remote-first content rails with stable card geometry, clear gold/green focus language and provider-aware loading/error isolation. TV, Filmes and Séries remain primary mental model.

## Search
Single search surface across enabled providers, with source attribution and progressive results. Provider failure does not erase successful results from others.

## Details
Artwork, title/metadata, provider/source actions, continue/play, episodes where applicable, favourites/library. Avoid duplicate metadata blocks.

## Live TV
Channel rail/grid + now/next EPG. Player opens immediately; guide and channel switching remain lightweight. Seek controls appear only when the live window is seekable.

## Settings
Account/profiles/devices, providers/addons/PT•HUB, playback/subtitles, language, sync and diagnostics. Product language follows device locale unless user explicitly overrides it.

## Player
Shared VOD/live visual system. Live adds LIVE badge, live-edge offset, Return to LIVE and truthful timeshift window. Controls must not cover essential subtitles/content longer than necessary.
