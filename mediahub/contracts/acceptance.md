# MEDIA•HUB acceptance definition

The project objective is a complete, functional and stable MEDIA•HUB application ready for real installation and testing. A demonstration, prototype or collection of build-time patches does not satisfy acceptance.

The transformed application must retain the useful NuvioTV foundation while owning its product identity, cloud/auth contract and UX. Core user paths must work together in one candidate: launch/onboarding, account/QR, profiles, Home, search, details, providers/PT•HUB, VOD playback, subtitles, Live TV/EPG, truthful timeshift, settings/sync and relaunch continuity.

No feature may be marked complete solely because a schema, mock, placeholder UI or bootstrap endpoint exists. Completion requires integration into the actual Android runtime and evidence through the release checklist.
